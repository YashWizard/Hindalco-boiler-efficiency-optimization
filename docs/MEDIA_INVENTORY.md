# Media disposition

The collection contains seven unique saved notebook PNG plots, one original plant dashboard screenshot and 28 Excel chart XML definitions. These were extracted into the private local review directory outside both repository folders. No original images or chart records are included here because they may expose industrial measurements or identifiers. Workbook chart definitions were not rendered or recalculated; their project attribution remains unresolved.

`assets/architecture.svg` is a newly created, data-free explanation of inspected source paths. It is not an original project deliverable or evidence of plant deployment.
