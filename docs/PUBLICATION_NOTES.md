# Publication and provenance

These folders were assembled from the original local project collection. The original files were not edited, renamed or deleted. No project scripts, notebooks, optimization, training or external integration were executed during packaging.

## Changes made for this repository

- Copied distinct source variants into descriptive locations; original paths and SHA-256 digests are recorded in `file_inventory.csv`.
- Replaced credentials, private service addresses, model-run references, local paths, plant identifiers and database schema names with placeholders or consistent aliases.
- Removed notebook outputs, execution counts, attachments and environment metadata. Original cell ordering is retained.
- Deduplicated copies after sanitization. Checkpoint/archive variants with distinct remaining content are retained and identified.
- Kept broken scripts, externally connected integrations and attribution-sensitive experiments as `.py.txt` reference source. This extension is intentional; these are not executable entry points.
- Created README documentation, source guides and data-free architecture diagrams during this packaging task. They are new documentation, not original internship deliverables.

## What is not included

Original industrial CSV/Excel data, raw logs, proprietary endpoint/tag mappings, archives, original plant dashboard screenshot and original notebook plot images are withheld. Media were extracted locally for review; these assets may contain confidential process data and identifiers. The unassigned workbook contains chart definitions rather than embedded photos.
